# Portafolio · Miguel Ángel González

Portafolio personal: proyectos, stack y contacto.

**🌐 En vivo:** https://exoticdevelopment.github.io/mi-portafolio/

## Stack

`React 19` · `TypeScript` · `Vite` · `Tailwind CSS` · desplegado con **GitHub Actions → GitHub Pages**

## Correrlo local

```bash
pnpm install
pnpm dev
```

Cada push a `main` construye y publica el sitio automáticamente (`.github/workflows/deploy.yml`).
